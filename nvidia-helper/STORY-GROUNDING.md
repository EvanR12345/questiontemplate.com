# Source-grounded story visuals

This update protects the existing director/image provider pipeline without
changing models, generation steps, resolution, character references or cadence.

## Source validation

- Casting explicitly retains individually staged unnamed prop holders. A narrow
  coverage guard detects omitted foreground women with props, asks for one
  evidence-backed correction, then fails safely if coverage is still missing.
  It does not regex-invent characters or make every bystander permanent.
- The normal source-continuity review also receives deterministic explicit
  object-owner contradictions. One correction may select another accepted cast
  ID; unknown owners cannot be guessed. Ambiguous pronouns and handovers stay
  with the director. A repeated explicit contradiction blocks saving the plan.
- New image requests from a saved plan with an explicit ownership contradiction
  fail before standalone GPU rental. Existing exports remain usable. An explicit
  manually authored prompt is preserved as the user's override.

These conservative guards are not a full semantic parser. They catch selected
demonstrated mistakes; source/storyboard reviews remain necessary.

## Persistent continuity versus visible facts

Location changes archive local environmental facts by location and retain a
separate environment history. Time/weather/season remain global. Old room props
do not become instructions for the next room. Legacy snapshots have unreliable
local provenance, so local visual details also need current action/narration,
pose, lighting or composition evidence. Unframed inventory is not required in
every picture. Permanent identity, current clothing, injuries, restraints and
identity accessories remain distinct from incidental held props.

The prompt compiler removes repeated exclusions and duplicate reference-state
text. Reference prompts still supply appearance facts absent from a saved or
manual prompt. There is no hard word cutoff or silent source truncation.

## Visual checks and spending

Practical checks retain advisory differences. If automatic repair is enabled,
only confirmed major findings with an edit/regenerate instruction are eligible.
Uncertain findings remain for review. Strict mode retains its broader review
policy. Neither mode bypasses project API/GPU caps or the existing verified
combined QC/replacement/recheck/rental overhead ceiling of 10 percent.

The first request to repair an existing image counts as a replacement. Repair
limits no longer buy an extra initial replacement. Repairing uses the current
selected image, preserves old versions, and records the source path. Failure at
the last allowed attempt raises the actual error instead of trying to save an
undefined result. Identity references are not silently dropped to fit editing.

Settings show Off, Enabled or On hold explicitly. Readiness displays visual
check level, repair budget requirements and known source contradictions. A
checks-off export can be labeled ready without falsely certifying visual quality;
failed attempt history and flagged images are retained.

## Evidence boundary

Offline regression tests cover source/casting correction bounds, owner evidence,
room changes, manual edits, reference appearance, replacement limits, saved image
history, cloud cache policy and existing production/queue/rendering behavior.
Timing profiles distinguish this grounding version from older observations.

Shorter prompt drafts and passing mocked tests do not prove improved generated
image quality or end-to-end speed. Saved images are not rewritten by installing
this update. Corrected hard-shot generation still needs a controlled comparison,
authorized reference transmission and the existing spending controls.
