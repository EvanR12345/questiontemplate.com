# Ten-style audition

Twenty original1280x720 PNG outputs: ten drawing styles, each rendered with FLUX.2 Klein4B FP8 and SDXL Turbo FP16. `source.png` is the exact full-resolution master corresponding to the user-supplied scene. `manifest.json` contains prompts, model settings and SHA256 values.

These are style tests. Model-specific identity/composition failures remain visible; no production default was selected. Files are original PNGs without lossy recompression.
