What changed in production

Checks no longer rewrite the entire project just to assign a chapter the status it already has. Queue synchronization also skips publication when the final statuses and timing history are unchanged. Real transitions and new timing receipts still save normally, with validation and backups.

When accepted-source/visual overlap is enabled for Lean Luna, one shared dispatcher keeps up to two accepted fact groups in flight. Ready requests from the next group can use spare API slots while an earlier slow request finishes. Chronological source decisions stay ordered, and the resulting plan keeps its original order.

Ownership and failure checks

The integration tests use the actual director adapter, API-slot limiter, execution journal and spending ledger with mocked replies. They verify four-slot limits and distinct owners, receipt draining after a sibling failure, no new retry or next-group purchase, and a retained positive reservation for an unresolved response.

346 regression tests ran successfully (0 skipped). External network calls were forbidden. The earlier memory-pressure failure was rerun in the clean final verification.

Limits of the numbers

The local timings depend on project size and machine load. The 22.2% scheduling result is a synthetic witness, not an API benchmark or a promise about the whole video. The dispatcher helps only when accepted groups overlap; a single group has no later group to fill its tail. Existing component timings continue to drive the planner until a matching production run is measured.

Reference-file reuse remains excluded from this release because its live benchmark is pending. No upload-speed gain is applied to the estimate.
